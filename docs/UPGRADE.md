# Upgrade from v0.3.x to v0.4.1

1. Quit the old Mawaqit Island app from its menu bar item (the installer also requests an exit).
2. From this directory, run `bash install.command` on your Mac.
3. The installer backs up the old app in `~/Applications` and launches the new build.
4. Mosque selection, favorite mosques, locally saved prayer timetables and preferences are kept.
5. Hover over the camera area to reveal the island. On a MacBook with a hardware notch, the compact state now has **two narrow black side wings** instead of one pill below the camera. The expanded header starts immediately below the notch.

This is a source preview: compile and verify the AppKit/SwiftUI UI on macOS before distributing publicly.
