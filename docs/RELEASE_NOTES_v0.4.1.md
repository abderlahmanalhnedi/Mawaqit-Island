# Mawaqit Island v0.4.1 🌙

**Download:** `Mawaqit-Island-macOS-universal.zip` (Intel + Apple Silicon, macOS 13+).

### 🇩🇪 Deutsch
**Installation:** ZIP herunterladen → entpacken → `Mawaqit Island.app` nach **Programme** ziehen → starten → Moschee auswählen.  
Bei macOS-Sicherheitswarnung: Rechtsklick → **Öffnen** oder **Systemeinstellungen → Datenschutz & Sicherheit → Dennoch öffnen**.

### 🇬🇧 English
**Install:** Download ZIP → unzip → drag `Mawaqit Island.app` into **Applications** → open → choose your mosque.  
If blocked, right-click → **Open**, or use **System Settings → Privacy & Security → Open Anyway**.

### 🇸🇦 العربية
**التثبيت:** حمّل ZIP ← فك الضغط ← انقل `Mawaqit Island.app` إلى **Applications** ← افتح التطبيق واختر المسجد.  
إذا منع macOS التشغيل، اختر **Open** بزر الفأرة الأيمن، أو **Privacy & Security → Open Anyway**.

### Features
- Notch-style auto-hiding prayer island with live countdown
- Public MAWAQIT mosque URL import and saved favorites
- Arabic / English / German; three appearance themes
- Five daily prayers, optional iqama and sunrise
- Independent community project; no account required

⚠️ **Security:** ad-hoc signed, **not notarized by Apple**. Do **not** disable Gatekeeper globally. Public MAWAQIT data integration is unofficial and can change.
