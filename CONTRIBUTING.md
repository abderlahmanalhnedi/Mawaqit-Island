# Contributing

Please open an issue describing observed behavior and the macOS version/architecture. Include **redacted** logs (do not post personal details, addresses, access tokens or credentials). Run `bash scripts/test.sh` and `bash scripts/build.sh` on macOS before submitting a PR.

No dependencies or copied code from SuperIsland, MAWAQIT's mobile app, or other unlicensed sources should be added. Prefer original SwiftUI/AppKit implementation and MIT-compatible assets only. Do not commit photos, local mosque data, or Apple signing certificates.
